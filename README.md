# 🌌 Attia Workspace - 极简高安全订阅网关

Attia 是一款基于 Python + Flask 打造的高性能、企业级安全订阅聚合分发面板。专为规避探测、保护节点真实源地址而设计。

## ✨ 核心特性

- **🛡️ 零信任网关架构**：首位注册者自动成为超级管理员。未授权用户无法访问任何前端 URL。
- **👁️ 无痕游客模式 (Guest Mode)**：游客登录的数据仅存在于内存中，重启或登出即刻销毁，不留任何痕迹。
- **🔒 底层 AES 加密入库**：所有导入的节点均使用 `Cryptography (Fernet)` 强对称加密写入 SQLite，即使服务器被连锅端，节点明文也不会泄露。
- **🤖 智能探针与纠错**：强大的 3x-ui 穿透嗅探引擎，自动去除错误路径，自动翻译报错信息，无视自签 SSL 证书拦截。
- **🌍 NLP 地名识别智能分发**：
  - **管理员下发**：基于自然语言识别节点国家（港/台/日/美等），强制开启随机混淆，保证各国家至少 2 个，死锁最高下发 10 个节点。
  - **个人订阅**：允许用户自主导入，支持开关混淆，超 20 个节点自动防滥用截断。
- **📱 极致的响应式 UI**：毛玻璃 (Glassmorphism) 设计，全端 8 大主流客户端 (Clash/Surge/V2rayN/QuanX等) 一键订阅，自带 5 国语言本地化储存。

## 🚀 一键部署 (Debian 11 推荐)

为了获得最佳体验，推荐使用一台干净的 Debian 11 VPS 服务器。我们提供了全自动化安装脚本。

### 1. 下载项目
将本项目克隆或下载 `.zip` 压缩包并解压到您的服务器（推荐路径：`/root/AttiaProject`）。

```
git clone https://github.com/knowbul1koli/Attia.git
cd AttiaProject
```

### 2. 赋予脚本执行权限并运行
在安装前，**请确保您已经将您的域名（例如 `attia.yourdomain.com`）的 A 记录解析到了这台服务器的 IP 上**，并且在 Cloudflare 中**暂时关闭小黄云 (DNS Only)**。

```
chmod +x install.sh
sudo ./install.sh
```

### 3. 安装向导
脚本将全自动为您完成以下工作：
1. 安装 Python3、Nginx、Certbot 等核心环境。
2. 安装依赖库。
3. 配置 Systemd 守护进程，使面板能够在后台永久运行且开机自启。
4. **提示输入域名**：填入您解析好的域名，脚本会自动配置 Nginx 反向代理，并申请部署 HTTPS (SSL) 证书。

部署完成后，在浏览器打开您的域名，**您注册的第一个账号即为最高权限管理员**。

*(配置成功后，您可以前往 Cloudflare 将小黄云点亮，开启 CDN 终极保护。)*

## 🛠️ 常用运维命令

部署成功后，系统已将 Attia 注册为系统级服务：

- **查看运行状态**：`systemctl status attia`
- **重启面板服务**：`systemctl restart attia`
- **查看实时日志**：`journalctl -u attia -f`
